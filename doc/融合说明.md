# DGE 融合说明：同济 sp_vision × 南京理工 rmcs

> 本文说明 DGE_vision_26 吸收了哪些两套开源方案的优势、改了哪些文件、怎么使用、还有什么没做。

---

## 1. 融合目标

DGE 的定位：

- 保留同济 `sp_vision_25` 的比赛算法完整度：多兵种、MPC 轨迹规划、标定体系、轻量部署；
- 吸收南京理工 `rmcs_auto_aim_v2` 的工程化能力：2D 像素 EKF、多目标模型、协方差收敛判据、Foxglove 3D、合成真值测试；
- 保持无 ROS 依赖：Foxglove 用官方 C++ SDK 直接 WebSocket 推流。

一句话：

> **同济负责“打得准、打得狠”，rmcs 负责“看得清、调得动、可回归”。**

## 4. 本次改动

### 4.1 标定工具

新增/启用：

```text
calibration/capture.cpp
calibration/calibrate_camera.cpp
calibration/calibrate_handeye.cpp
calibration/calibrate_robotworld_handeye.cpp
calibration/calibrate_validate.cpp
calibration/chessboard.hpp
configs/calibration.yaml
```

`capture.cpp` 改为从 YAML 读取棋盘格内角点数/方格尺寸，不再硬编码 10×7；棋盘格检测统一封装在 `calibration/chessboard.hpp`（`findChessboardCornersSB` + `cornerSubPix`）。

`calibrate_validate.cpp` 是新增的外参验收工具：

- 固定标定板 + 转云台；
- 把每张图的板位姿变换到 world；
- 输出位置/姿态 mean/std/max；
- 位置 std < 10 mm、姿态 std < 0.5° 视为通过。

### 4.2 EKF 诊断

`tasks/auto_aim/rmcs_ekf/rmcs_ekf.hpp` 新增：

```cpp
struct Diagnostics {
  State state;
  Eigen::Matrix<double, 11, 1> variance;
  Eigen::Matrix2d covariance_xy;
  double nis;
  double nis_threshold;
  double nis_fail_rate;
  double residual_norm;
  double dt;
  std::size_t update_count;
  std::size_t frame_update_count;
  int last_observed_id;
  bool converged;
  bool diverged;
  bool last_update_accepted;
};
```

`RobotModel` 新增：

```cpp
auto covariance() const -> const Covariance&;
auto diagnostics() const -> Diagnostics;
```

`Target` 新增统一入口：

```cpp
auto diagnostics() const -> rmcs_ekf::Diagnostics;
```

- 4 板：直接取 `rmcs_model_.diagnostics()`；
- 2/3 板 legacy EKF 已移除，不再有对应诊断映射。

### 4.3 legacy EKF 的 NIS 修正（已废弃）

> 2026-10-22：2/3 板目标（平衡、前哨站、基地）与 `tools/extended_kalman_filter` 已删除，本节仅保留历史记录。

### 4.4 Foxglove 曲线和 3D 椭圆

`/dge/debug` 新增：

```text
cov[0..10], sigma_x/y/z/vx/vy/vz/a/w/rf/rl/hl
nis, nis_threshold, nis_fail_rate, residual_norm
ekf_updates, ekf_frame_updates, ekf_dt
converged, diverged, last_id, uses_rmcs_ekf
```

3D `tracked_target` 新增 XY 平面 1σ/2σ 协方差椭圆。

### 4.5 鲁棒更新（NIS 门控 + 投影有效性）

`tasks/auto_aim/rmcs_ekf/rmcs_ekf.cpp`：

- 新增 `nis_gate_enabled`：NIS 超过 `nis_gate_threshold` 的灯条更新直接拒绝，不再让错误关联/遮挡把状态拉飞；
- 前 `nis_gate_warmup_updates` 帧不门控，避免初始化阶段误拒；
- 连续拒绝达到 `nis_max_consecutive_rejects` 后，对位置/速度/角度协方差加一个小量，避免滤波器“锁死”；
- 投影端点必须在相机前方（depth > 0.1 m）且 `projectPoints` 成功，否则跳过该灯条，避免把 `(0,0)` 当作观测；
- `predict(dt)` 对非有限/负 dt 直接跳过，`Target::predict` 对时间倒序做保护；
- `Diagnostics` 新增 `frame_rejected_count`、`nis_rejected_count`、`nis_consecutive_rejects`、`last_update_accepted`，Foxglove 可直接看。

配置示例：

```yaml
ekf:
  nis_threshold: 9.488          # 监控用 95%
  nis_gate_enabled: true
  nis_gate_threshold: 13.277    # 门控用 99%
  nis_gate_warmup_updates: 10
  nis_max_consecutive_rejects: 5
  nis_reject_cov_inflation: 0.01
```

## 5. 怎么用

### 5.1 构建

```bash
cmake -B build
cmake --build build -j"$(nproc)"
```

### 5.2 标定

```bash
./build/capture configs/calibration.yaml -o=assets/img_with_q
./build/calibrate_camera assets/img_with_q -c=configs/calibration.yaml
./build/calibrate_robotworld_handeye assets/img_with_q -c=configs/calibration.yaml
./build/calibrate_validate assets/img_with_q -c=configs/calibration.yaml
```

把输出填回 `configs/calibration.yaml`，再同步到 `configs/sentry.yaml` / `configs/daedalus.yaml`。

### 5.3 运行

```bash
./build/standard configs/daedalus.yaml
# 或
./build/sentry_DGE configs/sentry.yaml
```

Foxglove：

```text
ws://<机器人IP>:8765
```

导入 `foxglove_layouts/dge_debug_layout.json`。

### 5.4 看 EKF

- 曲线：`/dge/debug.nis`、`nis_fail_rate`、`sigma_*`、`center_err`、`yaw_err`、`vyaw_err`；
- 3D：`/dge/scene` 的 `tracked_target`，看 1σ/2σ 椭圆；
- 真值：`/sim/ground_truth`（仅仿真）；
- 判读：见 `doc/EKF调试.md`。

## 6. 还没做的部分

1. **自动化 EKF 回归测试**  
   rmcs 的 `test_robot_ekf` 是手动工具；DGE 目前也没有 `tests/ekf_sim_test.cpp`。建议后续补合成真值测试和 CI 阈值。

2. **ChArUco 支持**
   当前标定工具用棋盘格；ChArUco 更适合手眼和部分遮挡，可作为后续增强。

4. **实车 NEES**  
   没有真值就不算 NEES；实车只看 NIS/残差/重投影。仿真里可以补真值 NEES。

5. **多目标 map**  
   DGE 仍保留 `Tracker` 单目标 + 状态机；rmcs 的多 `DeviceId` map 可作为后续重构方向。

6. **时间同步**  
   DGE 已有 `imu_delay_ms` 概念；rmcs 的硬件触发 + RLS + IMU slerp 是更完整的方案，可作为后续独立改造。

---

## 7. 一句话总结

> 这次融合没有推倒 DGE 的算法，而是把 rmcs 的“可观测性”和同济的“可标定性”补进来：  
> **标定有工具、EKF 有协方差、NIS 有正确口径、Foxglove 有 3D 椭圆和真值误差。**
