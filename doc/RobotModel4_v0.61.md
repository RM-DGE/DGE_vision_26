# RobotModel4_v0.61：修复单板跟随

本版解决旋转目标的瞄准点长期固定跟随模型 0 号板，以及第二组板几何难以进入学习的问题。沿用 v0.60 的 11 维状态、像素观测、CWNA 和恢复框架。

## 本次更改

| 部分 | 更改及作用 |
|---|---|
| Aimer | 去掉 `!jumped()` 时固定返回 0 号板；普通/旋转模式按角速度判断，高低速延时取角速度绝对值；按预测命中时刻切板 |
| 几何初值 | 状态初值不变，初始几何 P 按允许范围设置下限；同一份 P 参与关联和 NIS，避免只扩大关联范围却拒绝首次几何更新 |
| 关联与确认 | 按 0/2、1/3 板组管理学习；结合完整更新、残差、有效时间跨度、协方差确认，确认后恢复严格候选范围；歧义帧只保留预测 |
| 恢复 | 主模型、窗口和候选使用一致门限；明确有进展的几何学习，不因此触发连续恢复失败，也不延长 LOST 截止时间 |
| 瞄准有效性 | 未确认几何只使用最近成功更新的板；空目标清除旧点，迭代不收敛时不发布有效瞄准点 |
| 记录和显示 | 默认初始化 priority；新增学习状态、计数及实际门限；回放执行 Aimer 并记录最终板号；Foxglove 增加两行状态文字，仍是五个曲线面板 |

日志 `manifest.json` 的 `algorithm` 和回放结束行标识为 `RobotModel4_v0.61`。新参数已在 `daedalus.yaml`、`standard3.yaml`、`sentry.yaml` 显式列出；旧配置缺这些键时使用相同源码默认值。Q/R 未调整，初始几何 P 的实际值有改变。

## 文件与编译

修改集中在 `tasks/auto_aim/aimer.*`、`armor.hpp`、`target.hpp`、`rmcs_ekf/`，以及 `tools/ekf_record.hpp`、`tools/ekf_replay.cpp`、`tools/Foxglove/foxglove.cpp`、CMake 和上述配置。新增一个算法检查源文件 `tests/ekf_algorithm_test.cpp`，不需要硬件或仿真器；不另建带版本后缀的程序。

正常程序仍按原流程编译。算法复测的命令、原始记录路径要求和通过条件见 [复测指南](EKF仿真测试指南.md)第 0 节。几何 P、候选门限和选板公式见 [EKF 技术文档](EKF技术文档.md)第 5 节。v0.60 文档保留作历史记录。
